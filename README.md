# 🎀 Kitty Campus Planner

대학생을 위한 **헬로키티 테마 할 일(To-Do) 관리 웹앱**입니다.
학과 일정, 아르바이트, 개인 할 일을 한곳에서 등록하고, 중요도와 마감일을 함께 관리하며, 전체 완료율을 한눈에 확인할 수 있습니다.

별도의 회원가입이나 설치 없이, 웹 브라우저만 있으면 바로 사용할 수 있습니다.

> 키티와 일정 관리해서 갓생 살자 ♥

---

## 🎯 프로젝트를 만든 목적

대학생은 수업·과제 같은 **학과 일정**, **아르바이트** 근무, **동아리 활동**, 그리고 개인적인 용무까지 동시에 관리해야 하는 경우가 많습니다. 하지만 이런 일정들이 여러 메모장이나 앱에 흩어져 있으면, 무엇을 먼저 해야 할지 우선순위를 파악하기 어렵고 마감일을 놓치기도 쉽습니다.

**Kitty Campus Planner**는 이런 문제를 해결하기 위해 다음을 목표로 만들어졌습니다.

- 학과 / 아르바이트 / 개인 할 일을 **하나의 화면**에서 구분해서 관리하기
- 중요도와 마감일을 함께 표시해서 **우선순위 판단**을 돕기
- 완료율을 시각적으로 보여줘서 **진행 상황**을 한눈에 파악하기
- 새로고침하거나 다시 접속해도 **데이터가 사라지지 않게** 하기

> 자세한 기획 내용은 [`PRD.md`](./PRD.md) 문서를 참고해 주세요.

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 🎀 헬로키티 테마 디자인 | 전체 테마는 **빨간색**, 캘린더 영역만 헬로키티 의상 색인 **청색**으로 구분되어 있어요. 페이지 배경은 헬로키티 배경 이미지, 곳곳에 키티 캐릭터 이미지가 배치되어 있어요 |
| 📅 주간 시간표 | **요일(월~금) x 교시(1~9교시)** 그리드에 과목을 등록하고, 과목마다 직접 색상을 지정해 구분할 수 있어요. 등록된 칸의 **[×] 버튼**을 눌러야만 삭제되어, 실수로 칸을 눌러도 지워지지 않아요 |
| ⏰ 마감 임박 학과 일정 요약 | 시간표 바로 아래에서, 마감이 **3일 이내**로 임박한 학과 할 일(과제/시험 등)만 모아서 D-Day와 함께 보여줘요 |
| 🗓️ 월간 캘린더 뷰 | 마감일이 있는 학과/개인 할 일과, 아르바이트 근무 요일에 해당하는 날짜를 **월간 캘린더**에서 한눈에 확인할 수 있어요. 이전 달/다음 달 버튼으로 다른 달도 확인할 수 있어요 |
| 🎀 캘린더 키티 스티커 | 캘린더의 각 날짜 칸에 **날짜 상태(마감 지남 / 마감 임박 / 여유 있음 / 일정 없음)**에 맞는 키티 표정 스티커가 자동으로 표시돼요. 캘린더 위쪽 **[캘린더 스티커 꾸미기]**에서 상태별로 원하는 키티 표정(울음/우울/안경/잠자는/냠냠/사랑/감기 키티)을 직접 골라 바꿀 수 있고, 선택한 설정은 저장되어 새로고침해도 유지돼요 |
| 🔍 캘린더 날짜 클릭 상세 일정 | 캘린더에서 원하는 날짜를 클릭하면, 그 날의 상세 일정(마감일 할 일 + 근무하는 아르바이트)을 목록으로 볼 수 있어요 |
| ✅ 할 일 추가 | 할 일 제목을 입력해서 목록에 새 항목을 추가할 수 있어요 |
| 🏷️ 카테고리 설정 | 할 일마다 **학과 / 아르바이트 / 개인** 중 하나로 분류할 수 있어요 |
| 🎓 학과 유형 설정 | 카테고리가 **학과**일 때만 **과제 / 시험 / 발표 / 팀플 / 기타** 중 하나로 세부 유형을 지정할 수 있어요 |
| ⭐ 중요도 설정 | 할 일마다 **상 / 중 / 하** 중요도를 지정할 수 있어요 |
| 📅 마감일 지정 | 카테고리가 **학과 / 개인**일 때는 마감일(날짜)을 지정할 수 있어요 |
| ⏳ D-Day 표시 | 마감일을 기준으로 **D-7, D-3, D-Day, 지남** 등 남은 일수를 뱃지로 자동 계산해서 보여줘요 (마감이 3일 이내면 강조 표시) |
| 🗓️ 아르바이트 근무 요일 지정 | 카테고리가 **아르바이트**일 때는 마감일 대신 **근무 요일(월~일, 중복 선택 가능)** 을 체크박스로 지정할 수 있어요 |
| 📝 메모 | 할 일을 추가할 때 **메모(선택 입력)** 를 함께 남길 수 있어요. 메모가 길면 카드에서는 일부만 보이고, **[더보기]** 를 누르면 전체 내용을 볼 수 있어요 |
| ☑️ 완료 체크 | 체크박스로 완료 여부를 표시하거나 다시 되돌릴 수 있어요 |
| 🗑️ 삭제 | 더 이상 필요 없는 할 일을 목록에서 삭제할 수 있어요 |
| 📊 전체 완료율 표시 | "완료율: 40% (2/5)" 형태로 전체 진행 상황을 실시간으로 보여줘요 |
| 💾 자동 저장 | 새로고침하거나 브라우저를 다시 열어도 등록했던 할 일과 시간표가 그대로 남아있어요 |

## 🖱️ 사용 방법

이 앱은 별도의 설치나 회원가입 없이 바로 사용할 수 있습니다.

1. `index.html` 파일을 웹 브라우저(크롬, 엣지 등)로 엽니다.
   - 파일 탐색기에서 `index.html`을 더블클릭하면 됩니다.
   - 또는 아래 **GitHub Pages 실행 링크**로 접속해도 됩니다.
2. 화면 맨 위 **주간 시간표** 영역에서 요일, 교시, 과목명, 색상을 선택하고 **[시간표 등록]**을 누르면 시간표 칸에 과목이 채워집니다. 등록된 칸 오른쪽 위의 **[×] 버튼**을 눌러야만 삭제되며, 칸 자체를 눌러도 삭제되지 않습니다.
   - 시간표 바로 아래 **마감 임박 학과 일정**에서는 마감이 3일 이내로 다가온 학과 할 일만 D-Day와 함께 모아서 볼 수 있습니다.
   - 그 아래 **월간 캘린더**에서는 마감일이 있는 학과/개인 할 일과 아르바이트 근무 요일을 날짜별로 확인할 수 있습니다. `‹` / `›` 버튼으로 이전 달/다음 달로 이동할 수 있습니다.
   - 캘린더 위쪽 **[🎀 캘린더 스티커 꾸미기]**에서 **마감 지남 / 마감 임박 / 여유 있음 / 일정 없음** 네 가지 상태마다 원하는 키티 표정을 골라두면, 캘린더 날짜 칸 오른쪽 위에 해당 상태의 스티커가 자동으로 표시됩니다. 고른 스티커는 저장되어 새로고침해도 유지됩니다.
   - 캘린더에서 **날짜를 클릭**하면 캘린더 아래에 그 날의 **상세 일정 목록**이 나타납니다.
3. 화면 중간 입력창에 할 일 제목을 입력합니다.
4. **카테고리(학과/아르바이트/개인)**, **중요도(상/중/하)**를 선택합니다.
   - 카테고리를 **학과**로 선택하면 **유형(과제/시험/발표/팀플/기타)** 선택 항목이 함께 나타납니다. (아르바이트/개인 카테고리에는 유형이 없습니다.)
   - 카테고리가 **학과 / 개인**이면 **마감일**을 지정합니다.
   - 카테고리를 **아르바이트**로 선택하면 마감일 대신 **근무 요일** 체크박스가 나타나며, 월~일 중 근무하는 날들을 여러 개 체크할 수 있습니다.
5. 필요하다면 **메모(선택 입력)** 칸에 세부 내용을 적을 수 있습니다. 비워두어도 할 일 등록에는 문제가 없습니다.
6. **[추가]** 버튼을 누르면 목록에 새 할 일이 등록됩니다. 마감일을 지정하면 목록에 **D-Day 뱃지**(예: D-3, D-Day, D+2 지남)가 자동으로 함께 표시되고, 아르바이트는 선택한 **근무 요일 뱃지**(예: 근무: 월·수·금)가 표시됩니다. 메모를 적었다면 카드 아래에 메모가 표시되며, 메모가 길면 일부만 보이고 **[더보기]** 를 눌러 전체 내용을 확인할 수 있습니다.
7. 완료한 할 일은 왼쪽 체크박스를 눌러 완료 표시할 수 있고, 다시 누르면 취소됩니다.
8. 더 이상 필요 없는 할 일은 **[삭제]** 버튼으로 지울 수 있습니다.
9. 화면의 진행률 바에서 **전체 완료율**을 확인할 수 있습니다.
10. 브라우저를 새로고침하거나 다시 열어도 입력했던 내용(메모 포함)과 시간표가 그대로 유지됩니다.

## 🛠️ 사용한 기술

이 프로젝트는 복잡한 설치 과정 없이 브라우저에서 바로 실행할 수 있도록, 아주 기본적인 웹 기술만으로 만들어졌습니다.

- **HTML** — 화면 구조(입력창, 버튼, 목록 등)
- **CSS** — 화면 디자인(레이아웃, 색상, 뱃지, 진행률 바 등)
- **JavaScript (바닐라 JS)** — 할 일 추가/삭제/완료 체크/완료율 계산 등 실제 동작 로직
- **localStorage (브라우저 내장 저장소)** — 서버나 데이터베이스 없이, 브라우저 안에 할 일 데이터를 저장해서 새로고침해도 유지되도록 함

> 별도의 프레임워크(React, Vue 등)나 서버, 데이터베이스를 사용하지 않아 구조가 단순하고 이해하기 쉽습니다.

## 📁 프로젝트 파일 구성

```
Kitty Campus Planner/ (저장소 이름: Smart-Campus-Planner)
├── index.html      # 웹페이지 구조 (화면에 보이는 뼈대)
├── css/
│   ├── style.css   # 화면 디자인 (색상, 레이아웃, 뱃지 스타일 등)
│   ├── 헬로키티 배경.jpg      # 페이지 전체 배경 이미지
│   ├── 앉아있는 헬로키티.png   # 헤더 타이틀 옆 이미지
│   ├── 꾸미기/                 # 각 섹션 소제목 옆에 배치하는 키티 꾸미기 이미지 모음
│   └── 키티 표정/               # 캘린더 날짜 상태별 스티커로 쓰이는 키티 표정 이미지 모음
│                                 # (울음/우울/안경/잠자는/냠냠/사랑/감기 키티)
├── js/
│   └── app.js       # 할 일 추가/삭제/완료 체크/완료율 계산/저장 로직 + 시간표/D-Day 로직
├── PRD.md          # 프로젝트 기획서 (목적, 요구사항, MVP 범위)
├── TASKS.md        # 단계별(T1~T3) 구현 계획 문서
├── PROMPTS.md      # 단계별 구현을 요청할 때 사용한 프롬프트 모음
└── README.md       # 지금 보고 있는 프로젝트 소개 문서
```

각 파일의 역할을 간단히 정리하면 다음과 같습니다.

- **`index.html`** : 사용자가 실제로 보는 화면(입력창, 목록, 진행률 바 등)의 뼈대를 정의합니다.
- **`css/style.css`** : 화면을 예쁘고 보기 좋게 꾸미는 디자인 규칙이 담겨 있습니다.
- **`js/app.js`** : 버튼을 눌렀을 때 할 일이 추가되거나, 체크박스를 눌렀을 때 완료 처리가 되는 등 앱의 실제 동작을 담당합니다. 또한 새로고침해도 데이터가 유지되도록 브라우저 저장소에 저장하고 불러오는 역할도 합니다.
- **`PRD.md` / `TASKS.md` / `PROMPTS.md`** : 이 앱이 어떤 목적과 계획으로 개발되었는지 보여주는 기획·개발 과정 문서입니다.
